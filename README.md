 EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
 
 AIM:
To create a 3D model from given orthographic projection.

 REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

 PROCEDURE:
1. Open Fusion 360, create a new design and select the XY Plane. Start a 2D sketch and draw the main rectangular portion with a length of 300 mm and a height of 150 mm using the Rectangle command. Apply the required dimensions using the Dimension (D) tool.

2. Draw two semicircular rounded portions on the left and right sides of the rectangle using the Arc command. Set the radius of both semicircular ends to R75 mm and ensure that both ends are symmetrical with respect to the centre line.

3. Draw two mounting holes at the centres of the semicircular ends using the Circle command. Maintain a centre-to-centre distance of 300 mm between the two holes. Add a small circular hole at the centre of the rectangular portion.

4. Create the inner rectangular and slot profiles inside the main body using the Line and Rectangle commands. Maintain equal spacing on both sides and follow the hidden-line arrangement shown in the drawing. Apply the necessary dimensions to the internal profiles.

5. Use the Trim command (T) to remove unwanted lines, overlapping arcs and extra portions of the sketch. Check that the outer boundary is completely closed and that all circular holes are properly positioned.

6. Finish the sketch and use the Extrude command (E) to create the required 3D base profile. Set the overall thickness to 110 mm according to the side view. Ensure that the extruded portion forms a single solid body.

7. Select the required face and create a new sketch for the central raised portion. Draw the rectangular vertical support using the Line and Rectangle commands. Maintain the specified step height of 60 mm and position it accurately at the centre of the base.

8. Draw the curved connecting portion using the 3-Point Arc and Line commands. Follow the curved shape shown in the front and isometric views. Apply the required radius and use the Trim command to remove unwanted portions.

9. Create the remaining holes, slots and internal cut-outs using the Circle, Rectangle and Extrude Cut commands. Maintain proper alignment and symmetry between both rounded ends and ensure that the central opening is correctly positioned.

10. Finally, inspect the complete model using the Isometric View and check all dimensions, including the overall length of 420 mm, height of 150 mm, central length of 300 mm, thickness of 110 mm, step height of 60 mm and rounded-end radius of R75 mm. Apply the necessary finishing operations and save the completed Fusion 360 design.
